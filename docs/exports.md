# Export formats

| Export | Contents | Purpose |
| --- | --- | --- |
| `drawing-face.vizij.glb` | Meshes, colors, morph targets, Vizij graph, and speech pose definitions | Load the animated face in Vizij |
| `drawing-vectors.svg` | Extracted shapes and colors | Edit the artwork in a vector editor |
| `drawing-features.json` | Shape data, colors, bounds, and feature labels | Retain or inspect extraction data |

The GLB does not contain recorded speech audio or a recording of the preview animation. The current interface does not import exported feature-map JSON files.
