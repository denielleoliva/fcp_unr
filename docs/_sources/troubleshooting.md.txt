# Troubleshooting

| Symptom | What to check |
| --- | --- |
| Paper shadows become shapes | Enable photo cleanup and reimport. |
| Light details disappear | Increase the paper threshold in normal mode, or use darker marks. |
| Solid colored areas disappear | Turn photo cleanup off and reimport. |
| Features move incorrectly | Correct all relevant region labels, including pupils, then rebuild. |
| Mouth remains open | Enable natural motion, keep the drawn shapes, and rebuild. Check that the manual mouth slider is at zero. |
| Face loses its drawn character | Enable **Keep my drawn shapes** and rebuild. |
| Speech timing is imperfect | Timing is estimated; voice and word-boundary support vary by browser. |
| Changes vanish after refresh | Export before refreshing; the studio has no persistent project save/load workflow. |
